# Git conventions

## Branches
- `feat/<short-name>`, `fix/<short-name>`, `chore/<short-name>`, `docs/<short-name>`
- No spaces; kebab-case.

## Commits
- Imperative, scoped when helpful: `feat(api): add employee search filter`
- One logical change per commit when practical.

## PRs
- Clear title; body explains **why**, test plan, and risk.
- Link issues / tickets when they exist.
