# Agent instructions — Spring / Java

Use the **spring-mosaic** MCP server for architecture review, Spring Boot quality standards, and PR review on this repo.

## First steps
1. `detect_spring_context`
2. `list_quality_domains` / `get_pr_review_brief` for reviews
3. `scan_violations` on changed `.java` / `.kt` files

## Pair with ai-mosaic
If this monorepo also has Angular UI, use **ai-mosaic** for frontend and **spring-mosaic** for backend.
